# ADR-0004: Go は最新の安定版を使う

- 状態: 承認
- 日付: 2026-11-22
- 決定者: プロジェクトオーナー（v0.1 計画の承認時）
- 関連: NFR-02、[docs/plans/v0.1.md](../plans/v0.1.md) D4・PR-1、ADR-0005

## 背景

`go.mod` の Go のバージョンを決める。計画時点の手元の Go は 1.24.3 だった。CI で `govulncheck` を必須にする（ADR-0005）と、サポートが切れた古い Go では標準ライブラリの脆弱性で CI が失敗する可能性がある。

## 検討した案

### 案 A: 最新の安定版に上げる

- 良い点: 標準ライブラリの脆弱性修正が入っている。govulncheck で失敗しにくい
- 悪い点: 手元の Go を更新する前提作業が要る。利用者が musubi をソースからビルドするときも新しい Go が要る

### 案 B: 手元の 1.24 に合わせる

- 良い点: 前提作業が要らない
- 悪い点: 1.24 のサポートが切れていれば、govulncheck で標準ライブラリの指摘が出て、その時点で上げることになる

## 決定

案 A を採用する。`go.mod` の `go` ディレクティブを最新の安定版にし、CI は `go-version-file: go.mod` で同じバージョンを使う。

## 影響

- 前提作業として、手元の Go を最新の安定版に更新する（docs/plans/v0.1.md）
- Go のバージョンを上げるときは `go.mod` だけを変え、CI はそれに従う
- 見直す条件: 新しい安定版が出て、前のバージョンのサポートが切れるとき（上げる作業は通常の PR で行い、ADR は要らない）
