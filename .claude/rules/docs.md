# ドキュメント執筆のルール

- 日本語で書く。文体は「〜する」「〜である」の常体
- 役割を分ける：requirements.md は「何を・なぜ」、design.md は「どう実現するか」。design.md は要件 ID（`F-xx` / `NFR-xx` / `E/W/Ixxx`）を引いて書く
- ID は振り直さない。廃止するときは欠番にする
- 決定したことは design.md 12 章「設計判断の記録」の表に追記し、見出し下の日付も更新する
- 未確定の事項は「（要確認）」と明記する
- 不採用にした案は、理由とあわせて短く残す
