# 受け入れ条件

- ブランチ: feature/<内容>
- マージ先: develop
- 最終判定: round <N> / 達成 <a> / 未達 <b>

## 条件

| ID | 条件 | 判定方法 | 由来 | 判定 | 根拠 |
| --- | --- | --- | --- | --- | --- |
| AC-1 | 大文字小文字だけ違うリンクで E007 が出る | `go test ./internal/rules -run TestE007_CaseMismatch` | E007 | 達成 | round 2 で確認 |
| AC-2 | `%20` を含むリンクで E007 が出ない | testdata `e007-urlencoded` のテスト | review-1 Blocking #2 | 未達 | resolve.go:42 でデコード前に結合している |
| AC-C1 | build / vet / golangci-lint / test が通る | `go build ./... && go vet ./... && golangci-lint run && go test ./...` | 共通 | 達成 | |
| AC-C2 | 変更した仕様・ルール・コマンド・データモデルに対応する docs / schemas が更新されている | reviewer が差分で確認 | 共通 | 達成 | 該当なし |
| AC-H1 | <人間の指摘> | <判定方法> | Thread PRRT_xxx | 未達 | |

- `AC-<n>`: 初回レビューで定義した条件（要件・Blocking の指摘・PR 内で直す Non-blocking）
- `AC-C<n>`: 毎回必ず入る共通の条件
- `AC-R<n>`: 再レビューで見つかったリグレッション（例外的に追加したもの）
- `AC-H<n>`: 人間のレビューから追加した条件

## 範囲外の指摘

計画の範囲（task.md の要件・やること・完了の目安、この PR の差分）の外にあるため、受け入れ条件にしなかったもの。PR 本文の「備考」と、計画の「次の候補」に回す。

| # | 重大度 | 内容 | 場所 | 理由（どの範囲の外か） |
| --- | --- | --- | --- | --- |
| X1 | Blocking 相当 | <既存コードのバグなど> | internal/…:42 | 差分で触っていない既存コード |
| X2 | Non-blocking | <計画に無い改善> | … | PR-4 の範囲 |

## 受け入れ条件にしなかったもの（範囲内）

| 種別 | 内容 | 扱い |
| --- | --- | --- |
| Non-blocking | <PR の範囲外の改善> | PR 本文の「備考」 |
| Question | <確認事項> | PR 本文の「レビューしてほしいポイント」 |
| 人間の判断 | <仕様・設計の変更が必要な点と選択肢> | PR 本文の「人間に判断してほしい点」 |
